# WebHub — HTML Practice Projects

A collection of beginner web development exercises built while learning HTML and multi-page website structure.

## Overview

This repository brings together small practice pages and supporting assets created to strengthen the fundamentals of front-end development.

## Getting Started

1. Clone the repository.
2. Open `index.html` in a web browser.
3. Navigate through the available pages.

## Project Files

- `index.html` — main page
- `contact.html` — contact page exercise
- `hobbies.html` — hobbies page exercise
- `solution.html` — reference exercise
- `assets/` and image files — supporting resources

## Learning Focus

- HTML document structure
- Linking pages together
- Working with images and static assets
- Organizing a small website

## Status

A learning project that can be extended with styling, responsive layouts, and accessibility improvements.
